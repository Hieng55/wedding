# Ngày Mình Chung Đôi

Website checklist và lập kế hoạch đám cưới sử dụng React, Vite và Firebase.

## Chạy dự án

```bash
npm install
npm run dev
```

## Firebase

Ứng dụng dùng:

- Realtime Database cho danh mục và công việc.
- Storage cho hình ảnh đính kèm.
- Analytics khi trình duyệt hỗ trợ.

Cần bật Realtime Database và Storage trong Firebase Console, đồng thời cấu hình Security Rules phù hợp trước khi dùng thật.
